# FARM Stack Project

This project is a simple FastAPI + MongoDB + React student management app.

## Backend

The backend lives at the repository root.

### Main files

- [`main.py`](./main.py) starts the FastAPI app and enables CORS for the React dev server.
- [`routers/student.py`](./routers/student.py) contains the student CRUD endpoints.
- [`models/student.py`](./models/student.py) defines the request body used by the API.
- [`schemas/student.py`](./schemas/student.py) converts MongoDB documents into JSON-friendly responses.
- [`config.py`](./config.py) connects to MongoDB using `MONGODB_API_URL`.

### API endpoints

- `POST /students/create`
- `GET /students/get`
- `GET /students/get/{student_id}`
- `PUT /students/update/{student_id}`
- `DELETE /students/delete/{student_id}`

### CORS

The backend allows requests from:

- `http://localhost:3000`
- `http://127.0.0.1:3000`

## Frontend

The React app lives in [`client/`](./client/).

It uses:

- React
- Bootstrap
- Axios

It provides a simple student form plus a table for editing and deleting records.

## Run It

1. Start MongoDB and make sure `MONGODB_API_URL` is set in `.env`.
2. Start the backend from the repository root.
3. Start the frontend from `client/`.

### Backend

```bash
uvicorn main:app --reload
```

### Frontend

```bash
cd client
npm start
```

## Notes

- The frontend talks to the backend at `http://localhost:8000` by default.
- You can override that with `REACT_APP_API_URL`.
- Student IDs are shown in the table, but they are generated by MongoDB behind the scenes.
